Hidden background
Occlusion tuning

For a see-through front face, try Face coverage around 1×. For narrow side channels, raise Wall coverage a little. Higher Depth tolerance protects foreground points but can allow more background through.

AI reconstructs up to four depth slices once per wallpaper. Slices follow foreground/background depth edges, independently of audio band count. Width and point sliders reuse cached colours. More points add GPU work; larger openings can expose imperfect AI detail.

Fill tuning

For gaps, raise Gap fill first; use Row spread for wider coverage. Lower Fill brightness for hotspots. High fill adds GPU work and memory and may reduce frame rate. Sharp depth edges remain unfilled.

AI fast uses Depth Anything V2 Small (~50 MB). AI detail uses Base (~195 MB) for finer depth, with a longer download and more memory while generating it. Models are cached; animation cost is unchanged. Base is licensed for non-commercial use.
