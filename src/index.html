Settings

Image

Tip: drag & drop or paste (Ctrl+V) an image any time.

Depth

Heuristic = instant luminance/salience guess. AI = Depth-Anything ONNX, downloaded once (needs the model URL to be reachable).

Points

Glow = overall particle brightness (all points). Boost = extra brightness only on the loud, moving ones. Point size is auto-compensated so the overall brightness stays put.

Motion

Bands affect the image where you map them:

Response shaping: gain scales the input, the floor mutes quiet sounds, and the curve decides how much quieter sounds move than loud ones. Higher curve = only peaks move.

Intensity scales both motions; Depth move = toward/away from you, XY move = sideways shimmer. Set XY to 0 for depth-only motion. Overscan zooms in a little extra so parallax never reveals an edge — it follows Parallax automatically, or set it yourself.

Audio

Wallpaper mode

Puts the visualizer fullscreen behind your desktop icons, click-through — it behaves like the OS wallpaper. Music keeps playing through it. Exit anytime from the tray icon (or this button).

Startup & games

Game mode: press Ctrl+Alt+D or use the tray menu to hide the wallpaper and free the GPU while gaming. Same keys to bring it back. With auto game mode on (Windows), any app that fills the screen — a game, a video — hides the wallpaper for you and brings it back when you leave.
